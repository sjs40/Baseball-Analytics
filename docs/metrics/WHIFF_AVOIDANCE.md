# Whiff Avoidance Above Expected v0.3

For an out-of-sample swing opportunity, whiff avoidance is
`P_OOS(whiff) - I(outcome = whiff)`. Positive values mean fewer whiffs than the
pitch-difficulty model expected. Totals and per-100-swing rates use modeled swing
opportunities; two-strike versions use two-strike swings. This is an experimental
retrospective metric, dependent on the OOS swing model and not a replacement for
Contact% or SwStr%.
